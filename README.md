# 活动商店交互演示源码

## 使用方法

1. 解压压缩包。
2. 双击 `index.html`，即可在浏览器中查看交互演示。
3. 建议使用 VS Code 打开整个文件夹进行修改。

## 文件说明

- `index.html`：页面结构、弹窗结构与界面文案。
- `styles.css`：颜色、字号、位置、间距与 3200×1440 画布样式。
- `app.js`：商品数据、分类切换、购买计算、库存更新与异常状态交互。
- `assets/`：商店图标、商品图片、空态和网络异常图片。

## 常见修改

- 修改商品名称、价格、库存：编辑 `app.js` 中的 `baseProducts`。
- 修改分类名称：编辑 `app.js` 中的 `categories`。
- 修改卡片尺寸、颜色或文字：编辑 `styles.css`。
- 替换图片：将新图片放入 `assets` 文件夹，并保持原文件名。

网页以 3200×1440 为基准尺寸，会根据浏览器窗口自动等比缩放。
